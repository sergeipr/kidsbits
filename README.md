# KidsBits 🌈

A single-page website of games and activities for kids. Everything lives in `index.html`, with no build step and no dependencies.

- 🐮 **Animal Sounds**: tap an animal to hear what it says
- 🔤 **ABC Fun**: tap a letter to hear it and see a word
- ➕ **Math Challenge**: three levels, earn stars for right answers
- 🧠 **Memory Match**: flip cards to find all the pairs
- 🎨 **Draw & Stamp**: draw with your finger or mouse, stamp stickers, save the picture

Stars and the child's name are saved in the browser.

## Run it

Open `index.html` in any browser. To host it, enable GitHub Pages on this repo, or drop the file on any static host.
